# Project OMNK

**Power Up Your Project SEKAI Experience**

Project OMNK is a community effort to develop and maintain tools that improve the experience of every Project SEKAI player and creator.

[Visit the website](https://omnk.org/)

## Features

- A full-window, animated ASCII display with a terminal-style appearance.
- A highlighted mission statement.
- Live clocks for UTC, Beijing (BJT), and Tokyo (TYO). On narrow screens, one clock appears at a time and changes every ten seconds.
- A GNOME-style blinking block cursor after the `sekaisync init` command.
- A responsive layout with readable text and extra spacing around the pause control on narrow screens.

## Controls

- **Click or tap `sekaisync init`** to visit [SekaiSync](https://sekaisync.omnk.org/).
- **Press Space or use the pause/resume control** to pause or resume the character animation and cursor blink. The clocks continue running.
- Reduced-motion preferences are respected. On phones that cannot keep the animation smooth, it pauses automatically and can be resumed manually.

## Keyboard Easter Egg

With the page focused, press **Enter on a physical keyboard** to open the [SekaiSync GitHub repository](https://github.com/omoinoki/sekaisync) in a new tab or window.

The cursor then disappears, and the Easter egg will not open another window during the same visit. Refresh or revisit the page to bring it back.
